# 使用指南

## 開始編輯

工作區中央的固定程式框包含「函式庫」和 `int main()` 主程式。從左側工具箱拖曳方塊到對應插槽，或使用工作區的搜尋功能尋找方塊；資料插槽只接受相容型態的方塊。右側程式碼面板會隨工作區變更即時更新。懸停方塊可讀取用途提示，點選診斷訊息可定位相關方塊。

可用「載入範例並開始教學」熟悉主程式、標頭檔與輸出。也可在工作區空白處拖曳移動畫布，使用滾輪縮放，或開啟小地圖快速定位。

## 專案與程式碼

- **自動儲存**：工作區和專案名稱會儲存在目前瀏覽器的本機儲存空間。選單提供自動儲存版本還原；可在專案管理中開啟多個專案分頁（最多 8 個）。
- **匯出專案**：產生 `.blocksmith.json`，包含工作區、專案名稱及自訂工具箱項目，可稍後匯入或移至另一個瀏覽器。
- **匯入專案**：接受 Blocksmith 匯出的專案 JSON。匯入會取代目前工作區；若工作區已有方塊，會先要求確認。匯入檢查失敗時，原工作區會保留。
- **匯出 `.cpp`**：下載目前產生的 C++ 原始碼，供外部編譯器或 IDE 使用。
- **積木檢查**：按 `F10` 檢查積木連接和必填值，不會啟動編譯器。
- **編譯並執行**：按「編譯並執行」或 `F11`，使用 Clang WebAssembly 編譯目前的 C++20 程式，並在瀏覽器中執行實際產生的程式。輸入面板內容會作為標準輸入，標準輸出、錯誤訊息和編譯診斷會顯示在輸出面板。

第一次編譯會下載約 28 MB 的編譯器資源，瀏覽器會快取資源以供後續使用。編譯及執行在背景工作程序內進行，程式碼不會傳送到外部編譯服務；超過兩分鐘的工作會自動停止。WebAssembly 執行環境與原生作業系統不同，部分依賴作業系統或未提供於 WASI 的 C++ 功能可能無法使用。

## 搜尋與方塊背包

搜尋支援方塊名稱、用途、分類、別名與代碼；可用方向鍵選擇結果並按 Enter 加入，也可在結果預覽中開啟詳細教學。方塊背包可將選取方塊所屬的連接程式組收納起來，稍後放回工作區；背包支援獨立 JSON 匯入與匯出。

搜尋歷史、收藏與常用方塊、輸入歷史、自訂版面及外觀偏好儲存在目前瀏覽器，不會隨專案 JSON 一併匯出。清除瀏覽器網站資料可能刪除尚未匯出的本機資料；重要專案請定期匯出備份。

## 快捷鍵

| 快捷鍵 | 操作 |
| --- | --- |
| `Ctrl/⌘ + K` | 開啟或關閉操作搜尋面板 |
| `F8` | 切換工作區小地圖 |
| `F10` | 檢查積木連接與必填值 |
| `F11` | 編譯並執行 C++ 程式 |
| `Ctrl/⌘ + Z` | 復原工作區操作 |
| `Ctrl/⌘ + Shift + Z` | 重做工作區操作 |

操作搜尋面板可搜尋並執行其他常用命令，包括匯入／匯出專案、定位主程式、縮放至內容及切換外觀。

## 外觀與配置

頂端控制列可切換淺色／深色模式和搭配色，並調整工作區與右側程式面板的比例。自訂配置可儲存並套用，最多五組；偏好設定只保存在該瀏覽器。

## 資料位置與限制

專案、自動儲存版本和偏好設定保存在目前瀏覽器的本機儲存空間，不會自動同步到其他裝置。匯出專案 JSON 可用來備份或移轉工作區。瀏覽器本機的 WebAssembly 工具鏈適合一般教學程式；完整原生系統 API、安裝於作業系統的套件和部分平台專屬功能不在其支援範圍。
